# Documentation Archive

Files in this directory are retained for historical context. They are not current
feature claims, priorities, or implementation instructions.

Use [Current Product and Engineering State](../CURRENT_STATE.md) for the current
standpoint and [Documentation Index](../README.md) for active guides.

## Archived groups

- `2026-pre-consolidation/` — plans, audits, handoffs, old status snapshots,
  release notes, legacy architecture/API/getting-started/testing material, and
  duplicated feature guides consolidated on 14 August 2026.
- `UI_MODERNIZATION.md` — earlier visual modernization notes retained from a
  previous archive pass.

Links inside archived files may point to their former top-level locations or make
claims superseded by the current product state.
